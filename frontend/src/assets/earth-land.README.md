# Earth land points

`earth-land.json` contains flattened `[longitude, latitude, ...]` coordinates for
7,661 land particles. The source is Natural Earth's public-domain 1:110m land:
https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson

Generated by projecting the source polygons onto a 1440 x 720 equirectangular
mask and retaining land points from 26,000 uniformly distributed Fibonacci-sphere
samples. Coordinates are rounded to two decimal places. This asset is bundled
locally; the globe does not request textures or map services at runtime.
